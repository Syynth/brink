# Search panel header — design canvas

Three directions for the Search panel's top piece, drafted after the
card surface (PR C) made the interim bordered references header
untenable ("this is dookie"). **Direction C (Chip.dc.html) is the
ruled design** (2026-08-24, decision-log "Search panel top: references
as a scope chip in the query box"): references identity as a
dismissible scope chip inside the query box, plus Direction A's flat
count+tools strip below the form.
