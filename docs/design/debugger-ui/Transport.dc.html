Transport states
Cluster renders only when the provider has the debug capability; disabled-not-hidden otherwise noted. Play is stepping: one live visualization, pause just stops the advance.

Ready (default — the story never plays on open)

Ready

Opening the studio starts nothing. Run compiles and begins the session; from the first revealed line the editor tracks execution live.

Playing

Playing

Pause armed; steps disabled. The editor's live line (success band) advances with each revealed line — playing IS stepping. Hitting an armed breakpoint moves to Paused without any mode switch.

Paused (breakpoint, step boundary, or F6)

Paused — tavern.ink:5

Pause becomes Continue. Step out disables in the Root frame; on a Thread frame it relabels "Finish thread" (never "step out").

Parked (condition-park)

Parked — resumes when its condition re-evaluates true

Nothing is running: stepping disables rather than pretending there is a next instruction. Condition-park wording, never "waiting for a value".

Out of sync (source edited past the running program)

Paused — source out of sync · Restart

Transport stays usable (the story still runs); only source mapping is suppressed — highlights vanish, gutter dots go hollow. Restart re-syncs.
