# E167

## Summary

A natural-notation `@[convention(claims = "…", order = N)]` handler declares a parameter that its pattern never captures, so a claimed line has nothing to bind it to.

This is the converse of `E160`, and the half only *claiming* handlers need. A `!name`-dispatched handler (`@[element(args = "…")]`) can also be called by hand with ordinary arguments, so a parameter no capture names is perfectly usable there. A claimed line is different: it is rewritten to **exactly one call** whose every argument comes from a named capture, so the pattern's capture set and the handler's parameter list must match exactly, not merely one way.

## Explanation

Issue #1838 and the 2026-07-31 ruling ("Conventions are annotated handlers", `docs/decision-log.md`) collapsed the declarative element table into an annotation surface. Issue #2164's 2026-08-03 ruling then split that surface in two: `@[convention(claims = "…", order = N)]` for pattern-claiming, `@[element(args = "…")]` for `!name`-dispatched, self-announcing handlers. A handler spelled with `claims = "…"` claims prose lines that announce nothing — a scene heading, a transition — and the compiler rewrites each claimed line into a single call on the handler.

Because the rewrite has no other source of arguments, the compiler checks the binding contract in both directions at the declaration:

- `E160` — a named capture that matches no parameter (it could never bind anything);
- `E167` — a parameter that no named capture matches (the rewrite could never supply it).

Reporting at the declaration rather than at a claimed line is deliberate: the defect is in the pattern/signature pair, and it would otherwise surface as a confusing error on whichever prose line happened to be claimed first.

## Example

```brink,fires(E167)
@[convention(claims = "^INT\\. (?<place>.+)$", order = 10)]
fn interior(place, mood) {
  return place;
}
```

`place` is captured; `mood` is not, so no claimed line can supply it.

## Fix

Either capture the parameter in the pattern, or drop it from the signature:

```brink,contrast
@[convention(claims = "^INT\\. (?<place>.+) — (?<mood>.+)$", order = 10)]
fn interior(place, mood) {
  return place;
}
```

```brink,contrast
@[convention(claims = "^INT\\. (?<place>.+)$", order = 10)]
fn interior(place) {
  return place;
}
```

If the handler genuinely needs an argument the line cannot provide, it is not a claiming handler — declare it with `@[element(args = "…")]` (the `!name`-dispatched spelling) and call it explicitly instead.
