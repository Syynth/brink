# E146

## Summary

RETIRED (issue #1508) — previously "an `as` binding in a choice guard (`* {if EXPR as name} [text]`) is ruled admissible (capture-at-presentation, by-value COW) but not yet implemented". Choice-guard `as` now lowers for real: the guard's `OptionBind` writes into the same frame `BeginChoice`'s thread-fork snapshots into the pending choice, so the captured value rides the pending choice through selection with no separate wire-level capture. Code kept reserved, not reused, for diagnostic-code stability — no longer emitted by any pass.
