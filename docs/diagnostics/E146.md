# E146

## Summary

An `as` binding in a **choice guard** (`* {if EXPR as name} [text]`). Ruled admissible with capture-at-presentation, by-value COW semantics, but **not yet implemented**: the captured value has to ride the pending choice across saves, which needs the `.inkb` v6 Choice record. Diagnosed by name so the construct never half-works — this is "not yet", not "not a thing".
