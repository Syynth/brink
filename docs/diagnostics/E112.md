# E112

## Summary

An `@[…]` annotation line outside a recognized placement — ink's leading run at the top of a knot/stitch body, or native's Rust-shaped position directly above a `flow`/`fn` declaration. Never a silent drop, never content — the `E045` posture, on the annotation channel.
