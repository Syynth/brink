# E159

## Summary

An `@[element(…)]` annotation whose `args` clause is missing, whose value is not a quoted string, whose value doesn't compile as a portable-regex pattern (`regex::Regex::new`), or which carries an unrecognized clause key.

The grammar counterpart of `E100` on the `@[effects(…)]` channel: the annotation parses as an annotation but declares a pattern this channel can't act on.
