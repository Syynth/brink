# E132

## Summary

A native file-level `@[was(…)]` rename record carries no quoted old module path — a missing argument, or one that is not a string literal. Native module paths are `::`-separated and travel as a string (`::` is not annotation-argument grammar), so the migration target must be spelled `@[was("story::old::path")]`. **Warning severity, never blocking** (see `DiagnosticCode::severity`): the malformed directive is skipped — no alias is produced — but the file still compiles. `brink-ir::hir::lower_native::module::lower_file_module` raises it rather than silently dropping the authored record.
