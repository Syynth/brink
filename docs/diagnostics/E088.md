# E088

## Summary

A bare-form `IMPORT { name } FROM mod` names a definition that the *declared* module `mod` does not publicly export. Only enforced against declared modules — an import naming an unknown/undeclared module is not itself flagged by this code, since this module's export set isn't visible to the check (modules-spec §2/§7).
