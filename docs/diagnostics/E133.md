# E133

## Summary

A native file's `root_content` carries something other than the one documented shape a native lowering may leave there: empty, or the single synthesized `flow main()` entry divert. Anything else — real weave content, more than one statement, a source-backed divert — is ink-only baggage: ink's pre-first-knot root weave has no native equivalent.
