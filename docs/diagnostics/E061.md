# E061

## Summary

A type annotation names something that isn't a recognized nominal type (`int`/`float`/`bool`/`string`/`divert`/`void`), a `list<L>` naming a declared `LIST`, `array<T>`, or `map<K, V>` — declared struct names arrive in TM-4.
