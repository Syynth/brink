# E061

## Summary

A type annotation names something that isn't a recognized nominal type (`int`/`float`/`bool`/`string`/`divert`/`void`), a `List<L>` naming a declared `LIST`, `Array<T>`, `Map<K, V>`, `Option<T>`, `Weighted<T>`, or `Handle<K>` — declared struct names arrive in TM-4.
