# E120

## Summary

NS-A7 `Weighted[T]` construction refusal: the compile-classifiable half of the E078-style evidence-by-construction split. Fired by the `weighted(…)` lowering for a statically-malformed table — an empty pair row, an odd (dangling-weight) argument count, or a **literal** weight that is not a positive int (zero, negative, float/string/bool). Computed weights are not classifiable here; they carry the construction *fault* residual instead (`RuntimeError::WeightedBadWeight`), so a table that exists is always rollable.
