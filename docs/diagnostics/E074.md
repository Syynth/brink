# E074

## Summary

A field-write target (`p.field = expr`) is a *chained* projection — `p.a.b = v` or a mixed `p.a[i].b = v` — never a bare `ident.field` on a resolvable root. TM-4c ships single-level field writes only (mirrors `lower_indexed_assignment`'s `n == 1` fast path); chained writes are an explicit, permanent T1e boundary (`docs/ typed-mode-spec.md` §6), not a "not implemented yet" gap — this is a real, reachable, non-suppressible diagnostic authors can hit by writing ordinary (if currently unsupported) ink, not a defensive backstop for a suppressed analysis diagnostic.

Also covers a write ending in an *index* whose index chain's own root is a struct-field projection or a mixed index/field access — `p.field[i] = v`, `p.a[i].b[j] = v`, or the mutator spelling (`push(p.field[i], v)`) — same T1e boundary, reached via `reject_field_projection_index_root` (issue #2121) rather than `try_lower_field_assignment`.

Also covers a bare-variable postfix `x++`/`x--` (§2's T1b block-statement form, and the classic `~` logic-line spelling) whose operand is a struct-field projection — `a.count++` — reached via the same `reject_field_projection_index_root` guard (issue #2894). Without this refusal the write would land on the whole record root rather than the field, the identical misroute #2121 closed for indexed/chained assignment.

## Explanation

A write can reach one level into a record: `p.hp = 5`, `p.hp += 1`,
`p.items[0] = x` where `p.items` is the whole root. It cannot reach two:
`p.a.b = v`, `p.a[i].b = v`, `p.field[i] = v`. Those are refused here rather
than lowered, because the only lowering available would write the value onto
the record root instead of the field, silently replacing the whole record.

The same refusal covers the postfix form on a field (`p.count++`,
`p.count--`), which would misroute the same way. The compound assignment
`p.count += 1` is the supported spelling of that write.

It is an `Error`. The boundary is permanent for chained writes
(`docs/typed-mode-spec.md` §6), not a gap waiting to be filled.

## Example

```ink,fires(E074)
STRUCT Counter = #{
    count: int,
}
VAR c = Counter#{count: 0}
~ c.count++
-> END
```

## Fix

Write the single-level field with a compound assignment:

```ink,contrast
STRUCT Counter = #{
    count: int,
}
VAR c = Counter#{count: 0}
~ c.count += 1
-> END
```

For a chained write, copy the inner record into a temp, write its field, and
assign it back one level at a time.
