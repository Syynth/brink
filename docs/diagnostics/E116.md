# E116

## Summary

A condition-position expression (an `if`/`while` condition, a `{cond: …}` conditional branch, a choice guard, an `await` condition) whose statically-known type is `Option[T]`. Option has **no** truthiness — truthiness is a quiet coercion of exactly the kind `Option[T] ≠ T` exists to ban — so a strict-mode author writes `== none` / `== some(x)`, or the `as`-binding; a bound condition never fires this check. Strict-mode-only, best-effort static (the "Unknown never disagrees" posture: an unclassifiable condition stays silently unchecked); under `types = gradual` the same condition is the `RuntimeError::OptionTruthiness` turn-terminating fault — the runtime backstop that catches every case either way. Supersedes NS-A1's shipped falsy-none truthiness.
