# E116

## Summary

A condition-position expression (an `if`/`while` condition, a `{cond: …}` conditional branch, a choice guard, an `await` condition) whose statically-known type is `Option<T>`. Option has **no** truthiness — truthiness is a quiet coercion of exactly the kind `Option<T> ≠ T` exists to ban — so a strict-mode author writes `== none` / `== some(x)`, or the `as`-binding; a bound condition never fires this check. Strict-mode-only, best-effort static (the "Unknown never disagrees" posture: an unclassifiable condition stays silently unchecked); under `types = gradual` the same condition is the `RuntimeError::OptionTruthiness` turn-terminating fault — the runtime backstop that catches every case either way. Supersedes NS-A1's shipped falsy-none truthiness.

A condition is *reached* at any expression depth a lambda literal can sit at — a VAR/CONST default, a temp initializer, an assignment, a return value, a divert/tunnel/thread-start argument, or a content interpolation can all hold a lambda whose own `|…| { … }` block body has a condition (issue #2764, same descent as E113's lambda-param coverage, issue #1773). Reaching it is not the same as classifying it, though: a condition inside a lambda's own body is checked only when its type is statically classifiable — off the *enclosing* def's finalized locals (a captured outer local, a global, or a direct call to an Option-returning intrinsic), or off the lambda's *own* param when that param carries a resolvable written annotation (issue #2782: `fn heal(x) { let f = |r: Option<int>| { if r { … } }; }` classifies `r` from its own `: Option<int>`). An unannotated param, and any name the lambda's own block re-binds via a temp/`for`/`as`-binding, cannot be classified — bare-name lookup has no shadowing frame of its own, and a re-bound name's fresh value is deliberately not inferred from whatever the shadowed annotation said (docs/typed-mode-spec.md §2's RULED #1912 firewall) — so those stay silently unchecked, same "Unknown never disagrees" posture as any other unclassifiable shape, with the `RuntimeError::OptionTruthiness` runtime fault as the backstop.
