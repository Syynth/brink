# E163

## Summary

An `@[style(…)]` annotation with no paired `@[element(…)]` on the same declaration.

`@[style]` is a companion annotation (`docs/prose-dialect-spec.md` §3.5b addendum 4): its keys name `@[element]`'s captures (plus the two special keys, `line` and `dispatch`), so a style declaration with nothing to style against is malformed rather than silently inert.
