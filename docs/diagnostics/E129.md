# E129

## Summary

A native construct parses cleanly but has no HIR lowering yet in this slice (a nested `module { … }` block, a `fn` declared below top level, a block used as a value, or any other CST shape `hir::lower_native` does not yet recognize). The construct is skipped — not silently: this diagnostic names exactly what was skipped and why.

Lambdas used to be on that list; they lower for real since issue #1685.

`-> knot(args)` divert/tunnel-call/return-redirect arguments used to be on
that list too (discarded and reported here rather than wired into
`DivertTarget::args`/`Return::onwards_args`); they lower for real since
issue #2136.
