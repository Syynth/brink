# E137

## Summary

The B0.9 native strict-only enforcement point: a native `.brink` file was compiled with an explicit `types = gradual` knob. Gradual typing does not exist on the native surface — `types` is not a project knob there the way it is for the transitional brink dialect, so an explicit `gradual` setting reaching a `.brink` compile is refused, loudly, rather than silently accepted.
